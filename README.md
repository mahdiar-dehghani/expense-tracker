# expense-tracker
A expense tracker built with Python

###### Features

The "Add an expense" button will allow you to input an expense, including the amount, category, description and date (which will be auto-filled).
List all expenses that were saved.
Data is stored in a local JSON file:

###### How to run

1. Install Python 3
2. Clone this repo
3. Run

python expense_tracker.py
